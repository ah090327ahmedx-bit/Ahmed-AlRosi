# أحمد الروسي 🇷🇺 — مشروع أندرويد مبدئي

هذا مشروع بداية لتطبيق أندرويد باسم «أحمد الروسي». النسخة المبدئية تفتح منتقي الملفات الرسمي في أندرويد، بحيث تختار بنفسك الصور أو الفيديوهات أو الملفات التي تريد مشاركتها.

## مهم
- هذا **مصدر مشروع** وليس ملف APK جاهزًا.
- لم يتم تضمين توكن بوت تيليجرام. لا تضع التوكن داخل التطبيق؛ يمكن استخراجه من APK.
- لم تتم إضافة إرسال تلقائي خفي أو مراقبة مستمرة لملفات الجهاز. أي مزامنة مستقبلية يجب أن تكون واضحة، بموافقة صريحة، مع إشعار وإيقاف سهل.
- الإرسال إلى تيليجرام يحتاج خطوة إضافية آمنة، ويفضل عبر خادم يحتفظ بالتوكن سرًا.

## فتح المشروع
1. نزّل Android Studio على كمبيوتر.
2. افتح مجلد المشروع في Android Studio.
3. دع Gradle يزامن المشروع.
4. من Build اختر Build APK(s).

قد تحتاج إلى تحديث إصدارات Gradle/Android Gradle Plugin حسب نسخة Android Studio المثبتة.
